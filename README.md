# ⚡ AI Text Summarizer

> **Turn Long Text Into Clear Insights**  
> A modern, responsive, SaaS-style web application engineered with **React 19**, **Vite**, **Tailwind CSS v4**, and **Lucide React**. Designed to integrate with a **Node.js + Express** backend, **Google Gemini API**, and **MongoDB**.

---

## ✨ Features

- **🎯 3 Summary Depth Modes**:
  - **Short**: Quick executive takeaways & key bullet highlights (~20% length).
  - **Medium**: Balanced synthesis capturing main supporting arguments (~40% length).
  - **Detailed**: In-depth analytical overview preserving context and evidence (~65% length).
- **📊 Real-Time Text Metrics**:
  - Accurate word and character counts as you type or paste.
  - Percentage reading time reduction calculation and estimated reading time saved.
- **📚 Smart History Archive**:
  - Searchable, persistent record of previously generated summaries.
  - Re-open old summaries to view both original source text and generated results.
  - Prepared for MongoDB cloud synchronization with local storage fallback.
- **⚡ Instant Export & Copy**:
  - One-click copy with visual confirmation.
  - Export summaries as clean **Markdown (`.md`)** or **Plain Text (`.txt`)** files.
- **💡 Sample Article Loader**:
  - Pre-loaded sample articles (*Healthcare AI*, *Clean Grid Energy*, *Hybrid Work*) for instant one-click testing.
- **🌓 Dark & Light Modes**:
  - System-aware, toggleable dark and light themes with smooth color transitions.
- **🛡️ Secure Client Architecture**:
  - Zero API keys or secrets exposed in frontend code.
  - Graceful connection error cards and an interactive **Backend Setup Guide Modal**.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
A `.env` file is configured with the backend API endpoint:
```env
VITE_API_BASE_URL=http://localhost:5000/api
```

### 3. Start Development Server
```bash
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for Production
```bash
npm run build
npm run preview
```

## 🔌 Backend Integration Specification

The frontend expects an Express.js backend running at `http://localhost:5000`:

### Endpoints Contract

1. **`POST /api/summarize`**
   - **Request Body**:
     ```json
     {
       "text": "Full document text to condense...",
       "length": "short" | "medium" | "detailed",
       "title": "Optional Document Title"
     }
     ```
   - **Response**:
     ```json
     {
       "success": true,
       "data": {
         "id": "sum_12345",
         "title": "Document Title",
         "summary": "Condensed summary generated by Google Gemini...",
         "length": "medium",
         "originalWordCount": 350,
         "summaryWordCount": 110,
         "createdAt": "2026-10-29T20:00:00.000Z"
       }
     }
     ```

2. **`GET /api/history`**
   - **Response**: Returns array of saved summary documents from MongoDB.

3. **`DELETE /api/history/:id`**
   - **Response**: `{ "success": true, "message": "Summary deleted" }`

4. **`GET /health`**
   - **Response**: `{ "status": "ok" }`
